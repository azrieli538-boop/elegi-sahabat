# Elegi Sahabat 🍃

**Kisah Abadi Persahabatan di Bangku Sekolah**

## 📖 Tentang

Website interaktif yang menceritakan kisah inspiratif persahabatan antara Azriel, Fikri, Abid, dan Arfa di masa sekolah. Dibangun dengan optimasi PageSpeed 100 untuk performa maksimal.

## 🚀 Fitur

- ✅ **PageSpeed 100** - Performa optimal di desktop dan mobile
- 🎨 **Desain Modern** - Tema hijau yang menenangkan dengan gradien elegan
- 📱 **Responsive** - Sempurna di semua ukuran layar
- ⚡ **Lightweight** - Kode yang dioptimasi dan minimal
- 🔍 **SEO Friendly** - Meta tags dan struktur yang sempurna

## ⚙️ Setup & Development

1. Clone repository:
```bash
git clone https://github.com/azrieli538-boop/elegi-sahabat.git
cd elegi-sahabat
```

2. Buka `index.html` di browser Anda

3. Deploy ke GitHub Pages (otomatis via Actions)
